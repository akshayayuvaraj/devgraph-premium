The graph decides what the agent does

Every question is turned into graph tool calls. What those calls return decides which tools run next, what is flagged, and which action is proposed.

1

Select tools from intent

Impact, history, ownership and path questions run different traversals. Unneeded tools are skipped and the trace says so.

2

Traverse multiple hops

Dependency chains, impacted projects, RELATED_TO incident history and developer ownership, all from stored relationships.

3

Separate fact from inference

Each evidence item is labelled direct (a stored edge) or inferred (derived from edges). Conflicts and missing owners are reported, never hidden.

4

Act only with your approval

The agent proposes a task with its evidence. Nothing is written until an authorized user confirms, and the outcome is linked back to the investigation.

Built for real investigations

Every screen reads live data from your graph.

Decision Trace

Selected tools, readable query summaries, entities and relationships retrieved, and whether an LLM or the evidence-only fallback answered.

Persistent memory

Investigations are stored in the graph per user, compared against the current graph on recall, and marked stale when facts change.

Interactive graph

Search, filter, zoom, inspect nodes, and see the exact evidence path highlighted for an answer.

Incidents & tasks

Search, severity and status management, owners, resolutions, and tasks, protected by role-based access.

Honest AI status

Works without an API key. When a model is configured, its answer is rejected if it cites evidence that does not exist.

Safe by default

Parameterized queries, CSRF protection, rate limits, hashed passwords, and credentials that never reach the browser.
